Objective:
Create a fully functional, responsive online shopping website for Algerian users (VetDz) that allows browsing products, selecting variations, filling order information, and submitting orders. Orders should later send an email to business owners and add a row to a Google Sheet.

Reference Materials:

Database schema: schema.txt (includes Admins, ProductTypes, Products with discounts, Variations, VariationValues, ProductVariations, Orders)
UI/UX design: public/ (mobile-first screens)
Typography: typography.png (specifies fonts, sizes, hierarchy)

Requirements:

Mobile-First & Responsive:
Base design on mobile screens provided, but website must be fully responsive across all devices (tablets, desktops). even though the provided screens show only mobile-view, the final implementation should be responsive across all devices.
Maintain layout logic (spacing, element placement) from the design, but adjust to be web-native rather than app-like. Avoid persistent bottom nav bars that conflict with browsers.
Arabic Localization:
All text in Arabic and right-aligned.
Maintain original element placement from the design (e.g., a left-aligned button stays left-aligned, but the text inside is right-aligned).
Use fonts that support Arabic characters and maintain readability.
Product Functionality:
Products can belong to Toppings, Leggings, Shoes, or future types.
Products have gender (Male, Female, Both) for filtering.
Each product may have multiple images (carousel), variations (size, color, etc.), and optional discounts (discount_active + discounted_price).
If a product has a discount, show the original price crossed out, the discounted price bold, and a dynamically calculated discount badge (integer percentage).
Variations & Orders:
Variations are defined per product type; products link to allowed variation values.
Users select product variations and fill order info: full name, phone number, wilaya, address, delivery type (home/desk).
Orders are submitted without payment integration.
UI/UX Adjustments & Logic:
If the provided screens contain illogical or missing elements (likely AI-generated), make design decisions to improve usability while keeping the aesthetic consistent.
Replace generic icons with meaningful, style-consistent alternatives if needed.
Contact and About pages should be enhanced to provide clear information, user feedback, location, and contact details.
Technical Notes:
Any UI library can be used as needed.
Maintain a clean, modern, and appealing design suitable for Algerian users.
Typography, spacing, and visual hierarchy must follow the provided design and font guidelines.

Deliverables:

Fully responsive web pages for Home, Product Details, About, Contact, and Orders.
Correct Arabic text alignment and font usage.
Interactive product carousels, variation selectors, discount display, and order submission functionality.
